# StarForge — контекст для ШІ

Цей файл читається автоматично на початку кожної сесії Claude Code. Тут — що це
за проєкт, як він влаштований і як у ньому працювати. Подробиці для людей —
`README.md` (усі команди адміна, таблиці рівнів, шанси, клани).

## Що це

**StarForge** — Telegram-гра: бот (Telegraf) + застосунок (WebApp) + активності в
груповому чаті. Колеса удачі, ризик ×2, спільний банк, ігри на зірки, сезонний
пас, ліга тижня, рівні з привілеями, завдання, друзі, клани з клановою війною й
битвами, справжні Telegram-подарунки (через Bot API `sendGift`).

- Мова всього — **українська** (тексти бота uk/en/ru, чат — українською).
  Коментарі в коді — українською. Відповідай власнику українською.
- Деплой — **Railway** (сервіс «giftbot»), `npm start` → `src/index.js`.
- Node ≥ 18.17, без збірки. Залежності: `telegraf`, `express`, `compression`, `dotenv`.

## Дві валюти й досвід

- **⭐ зірки** — справжні гроші: поповнення Telegram Stars, вивід, платні спіни, ставки.
- **🎫 білети** — безкоштовна валюта за активність. Обмін **10🎫 = 1⭐**; у банку 1🎫 важить як 5⭐.
- **XP** — одна шкала за будь-яку дію. Рухає водночас рівень (назавжди), сезонний
  пас (30 днів) і лігу тижня (з понеділка 00:00 Київ). Денні стелі по джерелах — `E.XP[src].dayCap`.

| `src/chat/chat.js` | усе в груповому чаті (одна велика замикаюча функція `createChat(bot)`) |

| `src/emoji.js` | карта преміум-емодзі (ключ → id) |

Порядок middleware у боті (`src/bot/index.js`) важливий: облік активності →
«перший коментар» → **модуль чату** (групи далі не йдуть) → техроботи → модулі →
текст у приваті (`hooks.onText`, `hooks.onStartPayload`) → старі кнопки.

## Правила коду (дотримуйся)

- **Гроші — лише через `users.move`.** Не патч `starBalance`/`tickets` напряму.
- **XP — лише через `progress.addXp`.** Джерела `admin` і `clan` не рахуються в очки кланів.
- **Захист від подвійного натискання** — синхронний прапорець статусу **до** першого `await`
  (`users.withLock` не гарантує). Так зроблено в подарунках, джекпоті, фіналі війни, битвах.
- **Преміум-емодзі в текстах** — токени `{:ключ}` (напр. `{:starIcon}`, `{:crown}`),
  `withEmoji(text)` замінює їх на `<tg-emoji>`; `i18n.t` робить це сам. Такі тексти —
  з `parse_mode: 'HTML'`. Екрануй користувацький текст (`esc`).
- **Картки** — заголовок + лінія `━━━━━━━━━━━━━━` + рядки + курсивний підпис
  (`ui.card` у боті, `card()` у чаті й кланах). Кнопки — `style` (`success`/`primary`/`danger`)
  та `icon_custom_emoji_id`. У приваті на кожному екрані — «НАЗАД» (`back_to_menu`).
- **Налаштування чисел** — у `src/economy.js`, не хардкодь у фічах.
- **Стан фіч** — `store.getFeatureFlags()` повертає **живий** об'єкт; `setFeatureFlags(patch)` —
  поверхневе злиття й запис. Клани: `featureFlags.clans`, у гравця — `u.clanId`.
- Пиши в стилі сусіднього коду: та сама щільність коментарів, імена, ідіоми.

## Основні фічі (де шукати)

- **Чат** (`src/chat/chat.js`): дропи, скриньки (9 закритих), вікторини, «хто швидший»,
  дуелі, ігри на білети, `/bonus`, квести дня, спільна ціль, активісти дня, серії,
  гаряча година, змагання, джекпот за активність, оголошення рівнів, `/me`, `/rank`, `/help`.
  Модуль працює лише в **прив'язаному** чаті (`/chat_here` адміном); пости — `chat.say(text, extra)`.
- **Клани** (`src/features/clans.js`, команди в чаті й у боті): кланова війна — подія на
  `CLANS.eventDays` днів; очки = XP учасників (у клані денна стеля XP ×2, понад стелю очки
  йдуть клану до 300/день); бонус за вступ/створення, скрині клану, особисті запрошення
  активних у чаті, **щогодинні битви** (чат / платні колеса / XP / ігри; клани проти «Одинаків»,
  живе табло), фінал із призами топ-3. Вхід для гравця — `/clan`; адмін — `/clanwar`.
- **Рівні** (`src/bot/levels.js`, `E.LEVELS`/`LEVEL_REWARDS`/`LEVEL_PERKS`): фото-картки,
  сторінки «Як апнути», «Привілеї», «Усі рівні».
- **Подарунки Telegram** — `src/features/tggifts.js` (`send(uid, tierId, text)`, каталог з fallback id);
  не вдалося — створюється заявка адміну (`applications.create`).
- **Заявки** — `src/features/applications.js` (підтвердження/відхилення з поверненням оплаченого).

## Тести й перевірка

```bash
npm run check   # синтаксис усіх src/ і web/js
npm test        # node --test test/*.test.js
```

- `test/server.test.js` — інтеграційні: справжній `src/index.js` проти **фейкового Telegram**
  (`test/helpers.js`). Фейк повертає `message_id: 1` на будь-яке `send*`, multipart-запити
  парсяться як `{}`. Усі виклики — у `tg.calls`.
- База засіюється **у старому форматі v2** (перевіряє міграцію): XP задається через `chatPts`,
  білети — `tickets`/`ticketsUsed`. Нових гравців додавай у `seedV2()`.
- Файл бази пишеться з затримкою — читаючи `readDb()`, чекай через `waitFor`.
- Бот сам шукає чат через ~3 с після старту (`getChat`) — у тестах чату спершу дочекайся
  цього, потім `/chat_here`, інакше прив'язку перезапише.
- Кожна нова фіча — з тестом; перед комітом `npm run check` і `npm test` мають бути зелені.

і розділ «Змінні оточення» в README.
